What’s in OxiDJ today?

Working local-library code. Acceptance is still open.

Persistent catalog
Stable track identities, technical facts, backup and restore.
File import
WAV, FLAC and MP3 references, with format-specific limits.
Provisional viewer
Search, sort, selection and track details. Not production approval.

What stays yours?

The source audio. The local catalog. The choice of ecosystem.

Reference-only
The current importer does not move or modify originals.
Local-first
No mandatory cloud account in the product direction.
Explicit boundaries
Embedded DJ tags, artwork, editing and playback are excluded today.
