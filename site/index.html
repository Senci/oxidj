08 / THE CONVERSION RITUAL

CONVERT YOUR LIBRARY. KEEP YOUR FINGERS CROSSED.

Nothing says pre-gig confidence like a warning label on your playlists.

The real-world inspiration + sources

Rekordbox warns that converting a Device Library over an existing OneLibrary overwrites it and can lose playlists or play history stored only there. OxiDJ does not currently offer OneLibrary export.

Rekordbox conversion warning ↗
09 / STREAMING SURPRISE

CHANGE THE QUALITY. REMIX YOUR CUE POINTS. UNINTENTIONALLY.

Your hot cues should be the surprises you planned.

The real-world inspiration + sources

Rekordbox warns that changing SoundCloud or TIDAL streaming quality can shift beat grids and cue points. OxiDJ does not currently offer those streaming integrations.

Rekordbox streaming-quality warning ↗

Before you start

Install Git, Rust via rustup and a native C toolchain. The repository pins its Rust toolchain. Use a writable local disk and a small test folder of audio; the catalog is capped at 10,000 tracks.

Import leaves original audio unchanged and reports each file's result. list prints track IDs, paths, digests and sizes. Embedded DJ tags, artwork, editing and playback are outside this CLI slice.

scripts/install-local.sh builds the CLI and the provisional library window with its two decks, and adds a launcher and desktop entry under ~/.local. It never touches library data.

CLI command definitions

1 Clone and build

git clone https://github.com/Senci/oxidj.git
cd oxidj
cargo build -p oxidj-cli --locked
cargo run -p oxidj-cli -- --help

2 Create a catalog and import a test folder.

Replace /path/to/test-audio with your folder.

cargo run -p oxidj-cli -- catalog init --db ./catalog.sqlite
cargo run -p oxidj-cli -- catalog import --db ./catalog.sqlite --dir /path/to/test-audio
cargo run -p oxidj-cli -- catalog list --db ./catalog.sqlite
