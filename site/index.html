Where the project stands.

Development stages, not release dates. The local library is in place; exchange, analysis and the real-library proof are in progress.

XML first. Hardware exchange later.

Rekordbox XML is a documented playlist interchange format. OneLibrary is a separate USB/SD library format used by compatible DJ hardware. One owner-run round trip through Rekordbox on Windows worked; that proves neither OneLibrary export nor DJ hardware support.

Format research and vendor sources

Try the CLI from source.

Linux is the exercised development platform; macOS and Windows are unverified, with no CI for them. This is a command-line build, not a packaged desktop release.

Install Git, Rust via rustup and a native C toolchain. The repository pins its Rust toolchain. Use a writable local disk and a small test folder of audio; the catalog is capped at 10,000 tracks.

Import leaves original audio unchanged and reports each file's result. list prints track IDs, paths, digests and sizes. Embedded DJ tags, artwork, editing and playback are outside this slice.

CLI command definitions

Build

git clone https://github.com/Senci/oxidj.git
cd oxidj
cargo build -p oxidj-cli --locked
cargo run -p oxidj-cli -- --help

Create, import, list. Replace /path/to/test-audio with your folder. 

cargo run -p oxidj-cli -- catalog init --db ./catalog.sqlite
cargo run -p oxidj-cli -- catalog import --db ./catalog.sqlite --dir /path/to/test-audio
cargo run -p oxidj-cli -- catalog list --db ./catalog.sqlite
