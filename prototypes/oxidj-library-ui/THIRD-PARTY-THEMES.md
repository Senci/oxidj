# Third-party theme palette attribution

OxiDJ adapts color palettes to its semantic UI roles, not editor syntax rules.
Catppuccin means **Mocha**; Ayu means **Dark**; GitHub means **Dark Classic**;
Dainty means Alexander Teinum's **Dainty Dark** (the article's One Candy Dark
link does not match its Dainty heading). Monaspace is a font, not a color theme.
Tokyo Day and the editable Custom palette remain available.

Colors are opaque RGB. Muted text and borders use brighter upstream swatches
where editor comment/separator colors would not be legible as application text
or control outlines. Dracula uses bright purple for muted text and purple for
borders; Ayu uses the opaque foreground RGB; Dainty uses sidebar text and
breadcrumb gray; GitHub uses lighter gray swatches; Atom One Dark uses main
text for muted text, its sidebar background for surface (#21252b), and an
adapted lighter neutral border (#828997). Focus uses
accent colors rather than low-contrast editor separators. Tests enforce text
contrast >=4.5:1 and outline/focus >=3:1 on both fills. These are adapted presets,
not claims of pixel-identical editor rendering or full accessibility qualification.
