## Recent important decisions

- **OxiDJ is MIT-licensed (ADR-009) — decided by the project owner.** `LICENSE` created; copyright holder Senad Ličina. This was not bookkeeping: it fired the conditional constraint in ADR-001, so **Slint is excluded at its free tier and egui/eframe becomes the framework to prototype**, and it excludes **Rubber Band** outright (already rejected independently — 208 lifetime downloads on its Rust bindings). Consequence now required: a **permissive-only dependency policy enforced as a build gate** — `cargo deny check licenses` with an allowlist (MIT, Apache-2.0, BSD-2/3-Clause, ISC, Unicode-DFS-2016, Zlib) and GPL/LGPL/AGPL/SSPL denied by default, wired into `M0-08`. An accidental copyleft dependency would silently change the licence of the distributed binary, so this is a gate rather than a convention. Noted but not acted on: Rust convention often duals `MIT OR Apache-2.0` (Apache adds a patent grant); trivially changeable now, needs contributor agreement later.
- **Audio engine foundation set, but as a candidate (ADR-008).** CPAL for device I/O with the time-stretch engine behind a replaceable trait, Signalsmith Stretch first — **medium** confidence, because *"CPAL is a reasonable Rust-first default, not proof of DJ-grade performance."* The decision's durable output is the **M0 data boundary**: stable track identities, source-frame positions, versioned beat-grid/analysis units, an explicit shared engine-frame clock, bounded timestamped commands, preallocated PCM transfer, defined underrun behaviour, and off-callback decoding plus device recovery. `rubberband` is ruled out on two independent grounds — GPL-2.0+/commercial licence **and** only 208 lifetime downloads, so its Rust bindings are effectively unproven. Verified crate health: `cpal` 24.3M downloads / `rubato` 13.2M / `cubeb` 526k / `signalsmith-stretch` 117k.
- **UI prototype confirmed; accessibility is the gating risk (ADR-001).** Prototype egui, compare Slint, **defer Qt rather than disqualify it** — Qt's maturity does not transfer to `cxx-qt`, which its own maintainers describe as pre-stable with frequently changing APIs, and the announced Qt Bridges may force further change. Slint's GPL/commercial terms are a *conditional* constraint rather than a veto. The prototype gate is explicitly **not a scrolling benchmark**: screen-reader table navigation, keyboard multi-selection and drag-and-drop must pass alongside the 500k-row performance target.
- ~~**OxiDJ has no licence file — this blocks two decisions.**~~ **Resolved 2026-10-15:** the project owner chose **MIT** (`ADR-009`), which settled the UI framework (Slint's free tier excluded → egui) and the stretch engine (Rubber Band excluded → Signalsmith). The new obligation it creates is a licence-enforcing build gate, not a further decision.
- **The ADR reviews changed two of the three positions — and none is accepted.** Sol/medium reviews ran one decision per packet, and the lead verified their load-bearing claims against primary sources rather than accepting reviewer confidence. **ADR-002 (persistence):** the reviewer rejected the ADR's own "high confidence" and returned **medium** — Litestream is optional rather than the backup strategy, a generic SQL-portability trait is replaced by domain-facing repository interfaces, and a 500k-track prototype is a precondition before the dependency enters the workspace. Verified: WAL gives reader/writer overlap but **not parallel writers**, and Litestream is asynchronous replication rather than verified-restore backup. **ADR-003 (metadata representation):** direction confirmed at high confidence, but with a counter-risk carried forward — per-field provenance does not capture relationships *between* fields, so an edit can invalidate retained opaque metadata while bytes survive. Import-edit-export validation is now decision-bearing and must be carried into ADR-005. **ADR-001 (GUI)** is deferred as a cheap-to-reverse prototyping decision. All four remain `Provisional`; every review attached a condition and the persistence precondition is unmet.
- **Sol is authorized for important work, tightly scoped, at medium reasoning.** The user's authorization: use tightly scoped Sol delegates at **medium** (high only rarely) for important decisions *and* important coding work. Applied as `delegation.provider=openai-codex`, `delegation.model=gpt-6.1-sol`, `delegation.reasoning_effort=medium`, `delegation.max_iterations=6`. Admission test for "important": expensive to reverse, affects data integrity or interoperability, sets a boundary others build on, or is genuinely hard Rust reasoning. Free Nous routes remain the default for routine and bounded work; PAYG still needs explicit approval. First intended use is the one-decision-per-packet review of the `M0-07` ADRs.
- **Static quality tooling is a precondition for Rust development, not a follow-up.** Every coding task handed back must run the repo-owned gate and paste real output as evidence; a task that has not run the gate is not complete however finished the code looks. The gate is tiered — a fast tier for every handoff, a heavier CI/scheduled tier — with machine-readable output for agents, lint policy committed in the repo, and `rust-analyzer` usable as a command-line analyser rather than only as an editor LSP. `M0-10` researches the exact tool set and time budgets from primary sources; `M0-08` implements it and `M0-09` verifies the evidence actually exists on the coding cards.
- **Architecture ADRs are `Provisional`, not `Accepted`.** `M0-07`'s first draft marked all four `Accepted` while the required independent review had not run. Corrected at integration to `Provisional`, and the draft also wrongly marked ADR-002 (persistence) and ADR-004 (crate boundaries) `sol_review: not-required` — both are review-mandatory. Scaffolding may proceed on the provisional crate layout because a fresh workspace has no data or published API to migrate; nothing may be presented as a settled architectural decision.
