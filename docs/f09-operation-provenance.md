# F-09 operation-oracle provenance

`xtask/tests/fixtures/f09-operation-provenance.json` freezes the bindings for all
50 current independent F-02/F-07 operation-oracle test targets: 42 F-02 and eight
F-07 targets, using 45 distinct synthetic input sources and 57 fixture artifacts.
They live in 26 checker files: the 25 guarded TRACK attribute edits (all except
Track Name) share the table-driven `xtask/tests/f02_track_attribute_edit_oracle.rs`,
one `const <ROW>: Case` row and one named test per attribute (test names are
unchanged from the former per-attribute files).
It supplements, rather than replaces, `f09_fixture_inventory.rs`'s F-01–F-12
baseline inventory and the existing A1 provenance.

Each binding records its case, checker source path, version
`f09-operation-oracle-v1`, source SHA-256, exact executable test function(s),
input path and complete input-directory artifact set. Artifact records bind
byte lengths and SHA-256 digests. The inventory itself is pinned by digest in
`xtask/tests/f09_operation_provenance.rs`; thus a coordinated manifest remapping
still requires an explicit change to the reviewed inventory pin. A checker that
loads a shared helper with `#[path = "common/..."]` (and any helper that helper
loads) binds each one under `checker.helpers` by exact repository path and
SHA-256: the Track Name support, the playlist-member append support, and the
shared element-tree decoder `xtask/tests/common/xml_tree.rs` used by the TRACK
attribute table and the folder/playlist oracles. Helpers are outside the
50-target and 57-artifact fixture inventory. The MVP F-09.1 binding row in `plan/MVP.md`
records this bounded provenance scope.

The manifest was inventoried from committed test and synthetic fixture bytes,
not generated by a production importer/exporter. Existing test-only quick-xml
decoder semantics (element-only, or text-preserving for the seven numeric-like
TRACK rows), manually specified expected edits/states, guard checks and semantic
mutation controls remain unchanged; checker and helper hashes bind those assertions.
Shared inputs are deliberate: the four TEMPO edits use accepted A1 F-07 bytes;
POSITION_MARK Start/End/Name share the two-mark Start fixture; Track Name uses
accepted A1 F-02. Directory artifacts include existing expected/provenance files
where present; there is no newly generated expected production output.

## Executable checks

```sh
cargo test -p xtask --test f09_operation_provenance
# Run any exact binding, using its checker file stem and recorded test name:
cargo test -p xtask --test f02_track_attribute_edit_oracle \
  independently_verifies_guarded_track_kind_edit_and_rejects_mutations -- --exact
cargo xtask ci
```

The validator discovers every `xtask/tests/f02_*_oracle.rs` and
`f07_*_oracle.rs`; derives one binding per (checker, input) group from each
test's actual `include_bytes!` input (a test whose body is `verify(&ROW)` uses
the input of table row `const ROW: Case`, otherwise the file's input) and
requires the ordered (checker, input, exact tests) list to equal the frozen
bindings; checks live checker and helper digests; checks the complete fixture directory sets; and verifies
all artifact bytes. A new target requires a reviewed inventory update, not an
unbound fallback. New naming conventions or external checker helpers require
extending this inventory's discovery/binding rules.

Disposable in-memory controls reject absent/duplicate bindings, unrelated test
or source mappings (including a TRACK attribute row bound to another row's input
or test), dropped helper bindings, missing identity fields, unbound targets, extra/missing
artifacts and checker/fixture byte drift (including same-length mutations).
No regression modifies the frozen files on disk.

This closes only the operation-oracle provenance/binding gap under ADR-005 §2
F-09.1 for these synthetic F-02/F-07 cases. It is not completion of all F-09
criteria, a storage/archive/plan qualification, a vendor-reader binding, or a
Rekordbox/OneLibrary compatibility claim. Global F-09 and A2/A3 qualification
remain **NOT DEMONSTRATED**. No private library data is used.
